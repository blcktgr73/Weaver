# TASK-050 Open the views a card leads to as new tabs instead of a split

Tracked in [Issue #102](https://github.com/blcktgr73/Weaver/issues/102). Ownership is recorded here; the Kanban column comes from the Issue ([DEC-003](../decisions/DEC-003-board-status-mapping.md), [DEC-005](../decisions/DEC-005-task-files.md)).

Opening a requirement, a task file, or a requirement source from the Overview split the editor beside it, and a second click added another group. Open them as new tabs in the same editor group so the views follow one another.

## Done when

- The requirement view, the task file, and the requirement source open as tabs of the active editor group.
- A requirement that is already open is shown again rather than opened twice.
- The guide says how these views open.
